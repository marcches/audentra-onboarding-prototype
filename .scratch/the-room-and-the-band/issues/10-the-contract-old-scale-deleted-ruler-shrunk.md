# 10 — The contract: the old scale deleted, the ruler shrunk

**What to build:** The old system stops existing, so no future screen can
reintroduce the compression that caused the complaint. This is the **contract**
half of the expand–contract, and it can only run once nothing reads the old
tokens.

Deleted rather than deprecated: the two type steps that made six steps live
inside five pixels, every half-step spacing utility, the duotone icon weight, and
the uppercase label. A deprecated token is a token someone uses again.

**The ruler shrinks from twelve invariants to nine, and gains a written
criterion.** Five go, because each polices an aesthetic this cycle deliberately
reversed — the signature confined to four files (which today fails the designer's
own request in CI), the rule that no Quest card may float, the rule that no sheet
may stretch, and the two closed Presence tables. Two arrive, because each is
verifiable and each answers a measured defect: one icon weight for meaning and
one for state, and no half-step in the spacing scale.

The criterion goes at the top of the file in prose, because this file has been
rewritten three times and every rewrite was caused by it holding taste still:
**assert a defect the client has reported more than once, never an aesthetic.**
Without that line there will be a fifth rewrite.

**Blocked by:** 03, 04, 05, 07, 08, 09 — every migrate batch.
